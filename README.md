
# 📊 School Exam Reports System

An Excel-based examination reporting system designed to simplify the management of student assessment records and automate report generation. This project demonstrates how Microsoft Excel can be used as a practical solution for educational data management without requiring specialized software.

## 📌 Overview

The **School Exam Reports System** enables schools and educators to organize student information, record assessment scores, calculate final results automatically, and generate well-structured examination reports.

This project was developed to improve efficiency, minimize calculation errors, and reduce the time required to prepare students' report cards.

## ✨ Features

* Student information management
* Continuous Assessment (CA) recording
* Examination score entry
* Automatic total score calculation
* Automatic grade computation
* Class position ranking
* Subject performance tracking
* Report card generation
* Organized worksheets for easy navigation

## 🛠 Technologies Used

* Microsoft Excel
* Excel Formulas and Functions
* Conditional Formatting
* Data Validation
* Lookup Functions (e.g., XLOOKUP/VLOOKUP where applicable)
* IF Statements
* Ranking Functions

## 📂 Project Structure

```text
SchoolExamReports.xlsx

└── Supporting Worksheets
```

*(Worksheet names may vary depending on the version.)*

## 🚀 How to Use

1. Download or clone this repository.
2. Open **SchoolExamReports.xlsx** using Microsoft Excel.
3. Enter student information.
4. Input Continuous Assessment (CA) and Examination scores.
5. The workbook automatically computes totals, grades, and rankings.
6. Review or print the generated report cards.
